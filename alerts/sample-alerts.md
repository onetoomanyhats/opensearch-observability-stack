# Sample Alerting Ideas

## Error rate spike
Trigger when 5xx responses exceed a threshold in a rolling window for a given service.

## Latency degradation
Trigger when p95 latency rises above an agreed SLO threshold.

## Ingestion anomaly
Trigger when event volume spikes unexpectedly, potentially indicating an incident or abuse pattern.

## No-data alert
Trigger if a service stops sending logs unexpectedly.
